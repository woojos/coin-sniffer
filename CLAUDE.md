Coin Sniffer: a top-down 2D browser game (Phaser 4, TypeScript, Vite). Game rules live in `src/core/` (unit-tested with Vitest); `src/scenes/` holds the Phaser rendering.

Every push to `main` runs `npm test` and `npm run build`, then deploys to GitHub Pages.

## Agent skills

- **Domain language**: name things with `GLOSSARY.md` terms. Single-context; read [docs/agents/domain.md](docs/agents/domain.md) before exploring or naming.
- **Issue tracker**: GitHub Issues via `gh`. Read [docs/agents/issue-tracker.md](docs/agents/issue-tracker.md) before any issue or PR operation.
- **Triage labels**: read [docs/agents/triage-labels.md](docs/agents/triage-labels.md) when a skill names a triage role.
